一键部署教程

全程约 5 分钟，不需要域名、不需要证书，也不需要懂 Linux。

第 1 步：准备一台 VPS

系统选 Debian 12 或 Ubuntu 22.04 / 24.04，内存 512MB 以上即可。不知道选哪个，看 VPS 选购指南。

购买后会收到服务器的 IP 地址和 root 密码。

第 2 步：SSH 登录服务器

Windows 10/11 和 macOS 自带 SSH。打开「终端」或「PowerShell」，输入（把 IP 换成你的）：

ssh root@你的服务器IP

第一次连接会询问是否信任，输入 yes 回车；输入密码时屏幕不显示字符，是正常的。

第 3 步：运行一键脚本

登录后粘贴下面整行命令并回车，在菜单中输入 1：

curl -fsSL https://raw.githubusercontent.com/gkismet/antivpn/main/install.sh -o install.sh && bash install.sh

脚本会自动完成：

  1. 开启 Linux 原生 BBR 拥塞控制
  2. 安装官方最新 Xray-core
  3. 生成 Reality 密钥、UUID，随机选择高位端口
  4. 配置 systemd 开机自启，放行防火墙端口（重启后自动恢复）
  5. 打印 vless:// 导入链接和二维码

以后随时在服务器上输入 vpn，就能重新查看链接、二维码，或重启、卸载。

第 4 步：导入客户端

平台客户端怎么导入
Windows / macOSv2rayN复制 vless:// 链接，在主界面按 Ctrl+V；底部勾选「启用 Tun 模式」
Androidv2rayNG右上角 + → 扫描二维码，右下角开启连接
iOSShadowrocket（小火箭）需海外 Apple ID 购买；打开后扫描终端二维码

为什么要开 TUN 模式？

普通「系统代理」只对浏览器生效。开启 TUN 模式后，终端命令、Git、Python、Cursor / Antigravity 等 IDE 都会走代理，开发时不用逐个配置。

常见问题与报错排查

按出现频率排列。没找到答案？到 GitHub Issues 或视频评论区留言。

部署与连接

部署成功，但客户端连不上
  1. 在服务器运行 systemctl status antivpn，确认显示 active (running)。不是的话运行 journalctl -u antivpn -n 30 看报错。
  2. 到 VPS 商家控制台检查安全组 / 防火墙，放行脚本显示的端口（TCP）。
  3. 确认电脑/手机系统时间准确，与服务器相差超过 90 秒会导致握手失败。
  4. 重新输入 vpn → 选 2，复制最新的链接重新导入，避免复制时漏字符。
输入 vpn 提示 command not found

旧版本脚本有这个问题，已修复。重新运行一次安装命令即可（会生成新的节点链接，记得重新导入）。

提示「以下必需工具安装失败: unzip …」

通常是软件源暂时不可用。Debian/Ubuntu 运行 apt-get update && apt-get install -y unzip jq curl，CentOS 系运行 yum install -y unzip jq curl，然后重新运行脚本。

BBR 开启失败

一般是 VPS 使用 OpenVZ / LXC 等容器虚拟化，不允许修改内核参数。不影响节点使用，只是长距离传输少了加速。KVM 架构的 VPS 都可以开启。

重启服务器后连不上

新版脚本会在每次服务启动时自动补上防火墙规则。如果你用的是旧版，重新运行一次安装命令即可。

需要买域名和 SSL 证书吗？

不需要。Reality 协议借用公开网站的 TLS 握手，不需要自己的域名和证书。

VPS 与 IP

住宅 IP 套餐售罄怎么办？

NTT 和 GTT 两条线路配置、价格相同，哪个有货买哪个；都售罄时可以在官网点「预订补货」，或者先选目前有货的 CG 线路（没有中国大陆线路优化）。实时库存见 选 VPS 页。

用住宅 IP 了，ChatGPT / Claude 还是提示 Access Denied
  1. 确认客户端真的走了节点：浏览器打开 ip.sb，显示的应是 VPS 的 IP。
  2. 开启 TUN 模式，避免部分流量绕过代理。
  3. 清除该网站的 Cookie，或用无痕窗口重试。
  4. 仍然不行的话，可能是该 IP 曾被他人滥用。联系商家说明情况，按其 IP 判断标准和退款政策处理。
CG 线路和 NTT/GTT 线路怎么选？

人在中国大陆、看重晚高峰速度，选有回程优化的 NTT/GTT；人在海外、预算优先或流量需求大，选 CG。详细对比见 选 VPS。

一台 VPS 可以几个人用？

Lite 套餐日常 1~3 台设备足够。多人共用或经常看高清视频，建议 Basic 以上，并留意每月流量。
